Now showing — Changes in —

An eBay listing displays an image hosted on this server. The address of that image never changes. The image does.

Hotlinking is the practice of displaying an image from someone else's server on your own page. The convention is that the borrower controls the page and the host controls the file — so the host can change what appears, at any time, without touching the page it appears on. Usually this is an accident, or a prank, or a bandwidth dispute. Here it is the work.

The listing shows one image from a set of 1,373: broken-image placeholders scraped from around the web, interleaved with generated photographs of demolition. A new one takes over every ninety seconds. Nothing about the listing changes. No two people arriving at different moments are looking at the same object.

The sale

An <img> is fetched once, when the page loads, and never updates — eBay strips the scripts that could refresh it. So whatever arrived when a buyer opened the listing stays frozen on their screen while they browse, decide, and check out. The server, meanwhile, has moved on. By the time a purchase completes, the object recorded by the transaction is not the object the buyer was looking at when they chose to buy it.

Every fetch is logged. At the moment of sale both images are recorded — the one on the buyer's screen and the one the ledger timestamps — and the listing is frozen permanently on the second. What the buyer receives is fixed by the transaction, not by the looking.
